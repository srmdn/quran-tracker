# AGENTS.md

Reusable collaboration rules for AI tools working in this repository.

## Operating Rules

1. Humans own all final decisions and commits.
2. AI output must be reviewed for correctness, security, and licensing before merging.
3. Do not include AI branding or co-author trailers in commit messages.
4. Keep changes small, traceable, and reversible.
5. Run `bun test` before every commit. All tests must pass.
6. No em dashes (`—`) in any written output: commit messages, docs, or code comments.

## Commit Ownership Standard

Commit messages must be human-authored. These lines are prohibited:

- `Co-authored-by: Claude ...`
- `Generated with Claude Code`
- `Co-authored-by: ChatGPT ...`
- `Generated by <AI tool/model> ...`

Use `scripts/check-commit-attribution.sh` before push.

## Security Work Protocol

Security issues must follow the governance process:

1. Apply the ai-governance-starter boilerplate before starting security work (already done).
2. Classify findings using `docs/risk-assessment-rubric.md`.
3. Tier 2+ findings require a decision record in `docs/decisions/` before implementing fixes.
4. Do not discuss specific security findings informally outside this process.

## Stack Notes

- Runtime: Bun (not Node). Use `bun:sqlite`, `Bun.file`, `Bun.serve()`.
- JSX: Hono JSX (`hono/jsx`), not React. Route files must use `.tsx` extension.
- DB: SQLite at `data/ngaji.db`. All queries use prepared statements.
- No build step for CSS: TailwindCSS loaded from CDN.
- Service restarts required to pick up code changes (no hot-reload in production).
